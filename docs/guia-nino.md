# Guía para el niño (para leérsela a Santi)

> Una guía corta para leerla en voz alta. Usa los íconos del juego como apoyo. Crece con cada incremento.

## ¡Hola, Santi!

- **El botón verde con un bloque** sirve para **poner** bloques. Elige un color y toca donde quieras construir.
- **El botón rojo** sirve para **quitar** bloques.
- **La flecha hacia atrás** deshace lo último que hiciste.
- **Para mirar alrededor**, arrastra con el mouse.

## Pronto (Fase 2)

- Tendrás un **personaje** con una "S" en la camiseta que camina con las flechas.
- Habrá **animales** en la granja: ovejas, vacas, gallinas, patos, cabras y el **cerdo-gallina**, que vuela.
- De noche saldrán **zombis** muy lentos. ¡Construye muros para cuidar a tus animales!
- Con el **collar** puedes hacerte amigo de un lobo.
- En la montaña de rocas hay **diamantes** para recoger con el pico.
